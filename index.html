Diagnóstico de Modelo

2. Validación de Supuestos de Residuos

Evaluación de normalidad (Shapiro-Wilk) y homocedasticidad (Levene) sobre los residuos del modelo factorial.

Resultados de Pruebas Estadísticas

Shapiro-Wilk (Normalidad de residuos) -> p-valor: 0.00046 ( No cumple normalidad )

Levene (Homocedasticidad) -> p-valor: 0.00787 ( No cumple homocedasticidad )

Justificación Metodológica: Al no cumplirse los supuestos paramétricos tradicionales con N = 466, se procede obligatoriamente al cálculo del modelo ANOVA incorporando la matriz de covarianza robusta tipo HC3, garantizando la validez de las pruebas de significancia.
